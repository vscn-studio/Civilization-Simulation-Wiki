## 手册 1：RKN 通用制作指南


RKN 通用制作指南

以下步骤适用于通常在工作台制作网格中制作的所有配方。

基础制作

要开始制作，手持第一个原料，瞄准一个表面，点击 rkncrafting.start + rightmouse。

制作台面出现后（显示为9个槽位），你可以将原料放在主手快捷栏中，瞄准对应的方格并点击 rightmouse 来添加第一个原料。继续添加原料，直到从你所站的角度填满配方网格形状。例如，如果你要制作一把 [handbook://item-knife-generic-flint] 燧石刀，你必须将一根 [handbook://item-stick] 木棍放在中间行或最近行的某个槽位中，并将一把 [handbook://item-knifeblade-flint] 燧石刀片放在木棍“上方”的槽位。如果操作成功，顶部信息框应显示“已选：燧石刀”。如果你绕着制作台面走动，你会注意到只有从正确的角度观察时配方才有效。

现在，你只需空手按住 rightmouse 即可制作物品！

工具使用

如果配方需要工具，比如 [handbook://item-wormgrunter] 诱蚯器，则不应将其放在制作台面上。相反，你必须先放置所有原料，然后在主手快捷栏或副手槽位中持有该工具的同时进行制作。

多步骤制作

如果我们查看 [handbook://block-figurehead-bear-oak] 熊首船首像的配方，会发现它需要4种工具。但你不能同时持有这么多工具（除非你是章鱼！）。解决方法是用这四种工具中的一种开始制作。此时制作不会生成船首像，而是生成一个未完成的船首像。要完成它，你必须将未完成的部分放到一个新的制作台面上，并使用另一种剩余工具。当你使用完所有必需的工具后，即可获得船首像。

注意：如果将锤子放在副手，锤子和凿子可以同时使用！

配方选择

如果原料恰好匹配两个或更多不同的配方，你可以通过瞄准制作台面并按 toolmodeselect 键来选择。

作为原料的工具

有些模组添加了消耗工具作为原料的配方。在这种情况下，你可以通过按 rkncrafting.start + rightmouse 将工具添加到制作台面上。请注意，当这种情况发生时，手册配方不会明确提示。
