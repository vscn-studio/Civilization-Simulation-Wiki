## 手册 1：浸制蜡烛


浸制蜡烛

油脂：日常用的蜡烛，取材于屠夫剩下的东西。

蜂蜡蜡烛出自烹饪锅。油脂蜡烛则是用熔化的动物脂肪一层一层浸制而成。

1. 炼制脂肪。在烹饪锅中把 [handbooksearch://脂肪块] 生脂肪煮成炼制脂肪，和做油灯时一样。

2. 熔化。把炼制脂肪再放进烹饪锅里煮，它会熔化成 [handbooksearch://熔融油脂] 熔融油脂，每块得两份。把锅留在燃烧的篝火上：火会让它保持熔融。离开火后，它很快会冷却，重新凝固成炼制脂肪，每两份得一块。

3. 制作浸蜡棒。一根 [handbooksearch://木棍] 木棍，加上四份 [handbooksearch://亚麻纤维] 亚麻纤维作烛芯。

4. 浸制。手持浸蜡棒对着篝火按住右键，给烛芯裹上一层，消耗一份油脂。每层都要先凝固片刻再浸下一层，否则挂不上。浸满六层即成蜡烛。

5. 割下蜡烛。把浸好的浸蜡棒和一把 [handbooksearch://小刀] 小刀放进合成栏，可得四根 [handbooksearch://油脂蜡烛] 油脂蜡烛，木棍也会还给你。

或者用模具。用粘土塑出一个 [handbooksearch://蜡烛模具] 蜡烛模具，放进窑坑烧制。把空模具放在地上，把装蜡的锅从火上取下，对着模具按住右键将其倒满——六份油脂，或十二份熔融蜂蜡，可做四根蜡烛。离火的锅在几个小时内仍可倾倒。等模具凝固后，手持两份 [handbooksearch://亚麻纤维] 亚麻纤维作为烛芯，右键点击即可取出蜡烛。模具每用一次都会磨损；用满十次就会开裂。

蜂蜡。蜂蜡也能在锅里熔化，每块得一份，用于模具——它太硬，无法浸制。

蜡烛头。燃尽的蜡烛头可以熔回原来的蜡，每个得一份。

彩色火焰。在合成栏中放入四份 [handbooksearch://亚麻纤维] 亚麻纤维和一份矿物粉末，可做出四根处理过的烛芯，燃烧时带有颜色： [handbooksearch://朱砂] 朱砂为红色， [handbooksearch://硫磺] 硫磺为黄色， [handbooksearch://硼砂] 硼砂为绿色， [handbooksearch://铜绿] 铜绿为青绿色， [handbooksearch://青金石] 青金石为蓝色， [handbooksearch://钾盐] 钾盐为紫色。粉末用石磨研磨；铜绿就是磨碎的孔雀石。用处理过的烛芯制作浸蜡棒或灌模，蜡烛就会燃出那种颜色，并用它照亮房间。颜色在烛芯里，所以蜡烛头会熔回普通的蜡。

染色蜡。把任意 [handbooksearch://染料] 染料和蜡一起煮——每块蜡配十分之一升，单独占一个锅格——蜡就会染上它的颜色，用它灌出或浸出的蜡烛也一样。浸制蜡烛的颜色取决于最后一层。蜡烛头熔回时是未染色的，可以在同一锅里再次染色。处理过的烛芯和染色蜡可以搭配使用：黑色的蜡烛，红色的火焰。

## 手册 2：蜡烛与维护


蜡烛与维护

蜡烛会燃尽。一根蜂蜡蜡烛大约能烧游戏时间两个月，油脂蜡烛约一个月——除非你的服务器改了设定——而且两者燃烧时都会明显变短。油脂蜡烛还稍暗一些，烟也更多。

烛丛。Shift+右键可放置一根蜡烛，或往烛丛里再添一根，最多九根。同一烛丛里的蜡烛一起燃烧。空手右键可取下一根——最后放上去的那根：烧过一部分的蜡烛会变成蜡烛头，它能燃烧剩下的时间，也能像蜡烛一样放置。蜂蜡和油脂不能放在同一烛丛里，但不同火焰颜色的蜡烛可以；房间会染上多数蜡烛燃出的颜色。

熄灭。空手Shift+右键点击烛丛、提灯或吊灯，可将其熄灭并保留剩余部分。用点燃的火把或起火器可再次点燃。点燃的蜡烛也能点燃火把。

燃尽。默认情况下，燃尽的蜡烛会残留微弱的余光。你的服务器也可能让它直接变暗，或者让蜡烛根本不会燃尽。

提灯一次燃烧一根蜡烛——起初是制作时用的那根，蜂蜡或油脂。手持蜡烛或蜡烛头右键点击提灯即可放入；旧蜡烛剩下的部分会还给你。油脂会熏黑玻璃，损失一点亮度。彩色玻璃无论烧什么蜡烛都会给光染色。拾起的提灯会保留其蜡烛的剩余部分。本就挂着的提灯（比如商人营地里的）有主人照料，不会燃尽——直到你放入自己的蜡烛。

油灯头。两块铜板和一根 [handbooksearch://亚麻线] 亚麻线可做成一个 [handbooksearch://油灯头] 油灯头，它代替提灯里的蜡烛：手持它右键点击提灯即可放入，蜡烛会退回来——把蜡烛换回去时，油灯头连同其中的油也会退回。用装有橄榄油或亚麻籽油的碗、水壶或木桶为它加油；它能装半升，可燃烧约四个月，是蜂蜡蜡烛的两倍，而且随时可以添满。亚麻籽油和油脂一样冒烟。空手Ctrl+右键可调低灯芯：亮度减半，油的燃烧时间加倍。手持空容器右键可把油倒出。空的油灯头无法点燃。

吊灯可放入蜡烛或蜡烛头，最多八根，燃烧方式与烛丛相同：蜂蜡或油脂，但不能同时混用——空吊灯两种都能放，由第一根蜡烛决定。空手右键可取出一根，燃尽的蜡烛也是这样清除的。

火把放置后会照旧燃尽，但现在拾起或从火把支架上取下时会保留剩余部分——向下取整到四分之一，不足四分之一则不保留。再次放置时，它只会燃烧剩下的部分。火把支架不会消耗其上的火把。

立即拾回。蜡烛或火把放错地方后在一小时内拾回，会恢复成放下时的样子。
