# 治疗与恢复：选对方法，避免重复用药

## 先区分要解决的问题

| 问题 | 对应操作 | 如何判断效果 |
| --- | --- | --- |
| 仍在出血 | 按压后包扎 | 出血速率下降，再观察血量。 |
| 伤口或皮肤污染 | 使用符合条件的洁净水清洗，按物品说明护理 | 查看脏污、伤口污染和保护状态。 |
| 感染或不适症状 | 使用当前模组实际提供、且适用于该病原或症状的物品 | 查看疾病阶段、症状及剩余时间。 |
| 失血后的恢复 | 停止新失血，保障水、已吸收蛋白质、能量及休息 | 血量与实际造血速度逐渐改善。 |

## 使用治疗物品

1. 按 C 查看疾病与伤口，确认需要治疗的对象。
2. 区分口服和外用。外用治疗是否要求伤口，要看该物品定义；要求伤口的物品不能对不存在的伤口使用。
3. 按物品操作提示使用，并保持动作要求。进度条出现不等于效果已完成。
4. 查看是否已经有同组治疗生效，再决定是否继续使用。

## 为什么不能连续重复使用

同组有效治疗不会简单叠加、无限延长时间。5 个生理小时内同组重复剂量会被记录，第二次及以后可能增加恶心和毒性；部分支持睡眠的治疗还会带来镇静效果。治疗本身也可能存在生效延迟。

具体止血、绷带与清洁操作见[护理教程](/guide/care-tutorial)，感染来源见[疾病百科](/guide/diseases)。治疗接口存在，不代表每种疾病都配有内置药品。

| 字段 | 默认值/范围 | 作用 |

| `Route` | `Oral` / `Topical` | 必须与调用路由一致 |
| `Pathogens` / `Symptoms` | 每项最多 16 | 匹配病原恢复速度或不适症状缓解 |
| `DelaySeconds` | 0–108000，默认 60 | 开始后延迟 |
| `DurationSeconds` | 1–2592000，默认 900 | 活性持续时间 |
| `Relief` | 0–0.6，默认 0.4 | 症状缓解 |
| `RecoveryBonus` | 0–1.5，默认 1 | 病原恢复速度加成 |
| `SleepSupport` | 0–0.3 | 睡眠质量加成 |
| `WoundRepair` / `CleanFraction` / `Hemostasis` | 0–1 | 伤口修复、清洁、止血；必须 `RequiresWound=true` |
| `WaterL` / `AlcoholL` / `Toxicity` | 0–0.25 / 0.05 / 1 | 饮水、酒精负担、药物毒性 |

## 实际应用规则

`Apply` 会验证状态、路由、伤口、唯一 receipt、同组活动效果和最多 32 个活动治疗；同组已有效果时保留更强定义但不叠加延长时长。5 小时生物时间内同组重复剂量会记录，第二次及以后可能添加 `nausea`；有 SleepSupport 会添加 `sedated`。毒性按 `Toxicity + (repeats >= 2 ? 0.2 : 0)` 累加，酒精按 `AlcoholL×20` 累加。

## 玩家操作建议

先用 C 键和 `/vsslssmod check` 判断不适症状/病程，再选择匹配病原或症状的物品；Topical 只能对有效伤口使用，口服治疗不能带伤口参数。连续重复使用会增加恶心和毒性，等待活动窗口结束。
