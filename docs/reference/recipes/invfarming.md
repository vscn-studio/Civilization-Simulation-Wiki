## 手册 1：农耕——处理休耕地

来源：`assets/invfarming/config/handbook/farming-fallow.json`。

每次收获后，你的耕地都会变成休耕地。要再次使用它，需要用你那把可靠的锄头重新翻耕。你也可以直接“破坏”休耕地以将其变回耕地，但这会使其每种养分损失 5%。

只要保持为休耕地，耕地的基础肥力就会 +10%，但也仅在此期间有效。一旦重新翻耕，其养分便会开始缓慢回落到常规肥力水平。最好在播种前才重新翻耕你的耕地，以获得最佳效果！
