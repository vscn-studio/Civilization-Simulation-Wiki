# 新玩家入门

本指南适用于清单中的文明模拟 1.0.0、生存模拟 1.0.3 和文明补丁 1.0.2。三者均需安装在客户端和服务端；游戏版本要求及安装包的依赖请参阅各模组页面。服务器可能调整玩法。

## 加入之前

1. 确认游戏版本及服务器要求，使用服务器指定的整合包版本。不要把服务端专用模组误认为客户端必需；逐项信息见[模组图鉴](/mods/)。
2. 初次进入世界时按提示填写角色姓名。出生聚落会影响初始位置；无法与朋友相遇时，请管理员检查聚落分配。
3. 短按 `Tab` 打开文明核心菜单，长按查看自己和部落在线成员；`Ctrl + Tab` 显示聊天记录。

## 第一天

按 `C` 查看身体状态，先寻找水、食物和避风处。对水源按住 `Shift + 右键`约 3 秒饮水，但天然水可能受到污染：尽快学习过滤、煮沸与蒸馏。不要一次忽略补水和休息；水与食物需要消化吸收，过度劳动会积累疲劳。

受伤后先离开危险、按住 `P` 按压止血，再处理伤口；`K` 可闭眼休息，床上睡眠有不同作用。`Shift + V` 排泄。按键均可在游戏设置中修改。按 `H` 查阅游戏手册，也可阅读本站[生存手册](/guide/handbook)。

## 与其他玩家生活

了解[部落、领地和地图](/guide/civilization)后再选址建设。默认禁止单人创建部落，服务器可以更改。交易时，指向 5 格内有报价的玩家并按 `Ctrl + T`。死亡和转生可能影响生命次数及归返，出发前先熟悉规则。

出现异常时，先记下操作步骤和模组版本；`/vsscsmod statuscopy` 可导出自身状态，`/vsslssmod check` 可查看生存状态。向管理员提供日志前，检查其中是否含不愿分享的信息。
