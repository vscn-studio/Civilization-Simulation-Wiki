## 系统机制

- [文明系统](/guide/civilization-source)：生命、归返、部落继任、授权、出生聚落和领地。
- [生存系统](/guide/survival-source)：启动顺序、服务端模拟、状态快照与外部动作。
- [兼容补丁](/guide/patches-source)：条件启用、石板负重、独立地图与数据所有权。

生理写入由服务端负责。客户端查询用于展示，返回副本不能用于修改世界或角色；外部动作必须先完成身份、权限、距离和库存检查，再按真实数量记账。饱食度、千焦、克、升、现实秒和游戏时间分别处理。
