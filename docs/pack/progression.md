# 整合包阶段推进

## 阶段一：可饮水与可休息

先获得稳定水源、容器和安全睡眠点。水源经过过滤或加热后再饮用，观察水量、核心温度、睡压和疲劳；不要用原版饱食度推断 Seraph 的能量储备。

## 阶段二：营养与卫生流程

使用[完整营养表](/guide/nutrition)和[原版/整合包食物检索](/guide/food-catalogue)安排宏量营养和微量营养，建立排泄物处理、洗手、清洁伤口的流程。食物表中的空白表示该分支没有静态声明，运行时仍可能通过原版营养属性、分类基线或配方回退；出现 `UnmappedPortions` 时再按服务器诊断排查。

## 阶段三：受伤与疾病管理

受伤后查看出血、疼痛、白细胞和伤口病原；出现不适症状后按[疾病阶段](/guide/diseases)确认病原路径，再使用适用于该病原或症状的治疗物品。重复剂量会产生恶心或毒性。

## 阶段四：文明与自动化

当基础生存稳定后，再推进部落、领地、工业、交通和兼容模组。每加入一个提供环境或伤口数据的模组，都用 `/vsslssmod compat` 确认唯一功能负责方，避免多个适配器重复计量。
