# 食物营养查询

按具体食物、加工状态和配方查询营养。可以同时搜索多个关键词，按营养含量排序、比较四种食物，或自行搭配餐食和馅饼。

## 查表方法

1. **查食物**：输入中文名称或物品代码，例如“胡萝卜”“game:fruit-redapple”。输入“苹果 烤熟”时，两个关键词必须同时匹配。食物名称、加工状态、模组名和配料都参与搜索。
2. **缩小范围**：按所属模组、营养类别、食品类型、加工状态、数据类型和食用方式筛选。选择“食材与成品”可暂时排除馅饼组合；选“馅饼配方”可查不同派皮与馅料。下拉菜单显示当前搜索下的匹配数量。
3. **找富含某种营养的食物**：选择“比较营养项”，例如蛋白质、铁或维生素 C，再选“从高到低”。最低、最高含量采用当前计量单位，未声明的数值不会被当作零参与范围筛选。
4. **公平比较**：选择“每 100 克”，勾选最多四种食品。若要比较一次实际吃下的数量，则选“按食用单位”：固体按个、液体按升、派按一片（四分之一整派）。
5. **带走结果**：“复制检索链接”保存筛选与计算条件；“导出筛选结果 CSV”导出所有匹配记录及完整营养列，不仅是当前一页。

“所属模组”也会匹配派的食材模组。例如，选择屠宰模组后，可以找到使用该模组食材的原版馅饼。筛选标签可单独移除；“重置筛选与计算”可恢复初始条件。

## 加工与食用量怎样影响数值

| 操作或状态 | 表中的处理方式 |
| --- | --- |
| 生食、烤熟、烟熏、盐腌、风干、发酵、磨粉等 | 分开列出实际物品状态；它们可能有不同份量、含水率和营养配方。展开“配料与加工说明”可跳转到关联的加工产物。 |
| 作为熟制餐食配料 | 有明确熟食配方时采用该配方及数量换算；没有时保留主要营养，按规则扣除部分热敏维生素。可制作的组合由烹饪配方决定。 |
| 烤派 | 按底皮 2 个面团、4 槽各 2 个馅料计算；加顶皮再投入 2 个面团。生派、半熟、烤熟、烤焦分别计算，默认展示整派的四分之一。 |
| 派皮失水 | 半熟、烤熟、烤焦的水分上限依次为质量的 50%、32.7%、20%；只减少多余水分，不凭空增加蛋白质或碳水。每 100 克浓度因此可能上升。 |
| 液体 | 默认展示 1 升，质量按液体密度换算。输入 0.25 即查看饮用 250 毫升的摄入量；容器本身的重量不计入。 |
| 肉排切块 | Rustic 肉排完整时按 6 块计算。剩余 3 块时，实际食用总量减半；每 100 克的组成不改变。 |
| 腐败 | 有效营养与能量乘以“1 − 腐败比例”。例如 25% 腐败保留 75% 有效营养；物理质量、水分、酒精和钠钾质量不因此减少，电解质营养点会减少。腐败不是食品安全建议。 |
| 实际制作的动态食品 | 部分香肠、混合餐和附加模组食品会保存实际配料。固定表提供默认配方，自己的成品可能不同，应按实际投入计算。 |

微量营养列显示**用于营养储备换算的有效摄入量**，包含模组规定的烹饪保留率与储备折算系数；不等于实验室测得的原始物理成分。身体最终吸收和储备增长还取决于消化过程、摄入量等条件。未经折算的每 100 克成分可在“校准与原版分支”中查看。

没有专门熟食配方时，熟制保留钙、铁和锌；维生素 A、C、B₁、B₆、叶酸、B₁₂的保留率分别为 80%、50%、70%、80%、70%、80%。已有熟制配方时不会再重复扣除同一轮损耗。

## 自己的配方怎样查询

在“自选配料计算”中选择炖肉、汤、谷物粥、炒蛋、炖蔬菜或果酱，填写四个食材槽。下拉菜单只列出该配方允许的材料，并按必需数量和类别验证搭配；不满足条件时不会展示一个看似有效的成品营养。食用份数可以是小数。

混合馅料派可自行选择派皮、顶皮、四槽馅料、烘焙程度和食用比例。不同馅料需要满足相同营养类别或共同混合标签等规则。每槽投入量固定为两个食材；输入的是**整个派的配方**，食用比例再决定此次摄入量。

特殊烹饪容器、勾芡、附加酱汁、额外盐分及第三方自定义属性不自动套用到普通烹饪锅示例。对于已经制作的食品，以它实际保存的配料与游戏内营养显示为准。

## 适用范围

当前目录展开具体物品变体，并按可用派皮、馅料、顶皮和四个烘焙阶段提供配方预览；页面顶部显示实际数量。配方组合与独立物品分别计数。414 条校准定义可覆盖多个物品与配方，因此校准条数并不等于可查询食物数量。非食品的容器、无效变体和手册排除的旧物品不用于增加数量。

数据区分具体成分校准、替代食材校准、配方计算和类别估算。“未声明”不是零；原版饱食度与 Seraph 的物理营养单位也不能直接混用。普通启用补丁和模组依赖已纳入静态展开，但服务器配置、代码模组运行时修改、自定义堆叠属性仍可能改变结果。本表不声称枚举了任意第三方代码生成的全部物品或无限种混合配方。
