# C 键窗口：看懂自己的身体

## 打开、查看与固定窗口

按 **C** 打开角色窗口，将鼠标停在数值上查看解释与变化来源。窗口有滚动条时可以向下查看；身体、血液循环、疾病恢复、功能、能量平衡和体温调节窗口可通过标题栏按钮固定，关闭 C 后继续显示。退出世界会清除本次固定记录。

## 按问题选择窗口

| 现在的问题 | 先看哪个窗口 | 接着观察 |
| --- | --- | --- |
| 喝水却仍口渴 | 身体与营养 | 胃水是否正在吸收，身体水量是否持续流失。 |
| 吃饱仍没有力气 | 能量平衡与营养 | 糖原、耐力、疲劳、睡压是否分别恢复。 |
| 受伤后状态恶化 | 血液循环与疾病恢复 | 出血速率、血量、伤口、疼痛与感染。 |
| 移动或劳动变慢 | 功能 | 查看对应倍率，再检查腿伤、体力和负重。 |
| 太冷、太热或发热 | 体温调节与环境 | 核心温度、调节目标、产热、散热、风和湿润度。 |
| 不清楚吃什么 | 营养与食品手册 | 已吸收营养储备和缺乏项，配合食物表选择。 |

全部指标的单位、含义和数值来源集中在[身体属性速查](/guide/metric-sources)；其他菜单见[全部窗口](/guide/windows)。

## 数值与趋势怎么读

胃内食物不等于已吸收营养；百分比有时表示能力倍率，有时表示储备或强度，不都代表概率。快照缺失、过期或空白也不代表零。热流显示正负方向，冷热适应显示的是效果增幅，不是完整训练进度。

## 窗口布局

| 面板 | 功能 |
| --- | --- |
| 身体/营养 | 水量、肌肉量、胃/肠道图、糖原/脂肪能量与营养储备 |
| 血液循环 | 血量、心肺、毒性、代谢 |
| 疾病恢复 | 卫生、免疫、白细胞、疼痛和可滚动疾病列表 |

| 环境 | 气温、湿度、风、通风、污染 |

### 营养窗口的特殊元素

- 胃部圆形图按水、碳水、蛋白、脂肪、纤维和残渣分层；旁边的肠道图按 `BowelUnits/5000g` 填充。
- 能量行显示糖原、脂肪能量和胃内能量；宏量营养显示当前值/最大值，微量营养显示 0–100 分数。
- 面板把铁和锌合并为 `ironzinc` 行，取两者相对储备较低者；D、K 和独立锌不单独展示。
- `NutritionHandbookDialog` 使用服务器同源的食品份量、能量、水和营养数据；未连接服务器时不会用客户端猜测值。

### 免疫窗口的特殊元素

- 疾病恢复面板在摘要指标下方显示疾病、伤口和综合症行，最多 80 行，内容区域可滚动。
- 没有疾病时显示 `effect-none`；快照过期时显示未知，而不是把 0 当成健康。
- 每行悬停文本来自服务器 `PanelMetric.Detail`，疾病行显示病原、阶段或 Complaint 详情。

| `bodywater` | 水量 | g | 可用水量（克）。基础失水 75 mL/h，出汗、疾病和出血另计。胃水半衰期为 1/3 游戏小时，吸收上限为 2000 mL/h；体水已满时，未吸收的水留在胃内；电解质和可用碳水支持水分留存，严重蛋白质或脂肪缺乏会小幅降低吸收。 |

| --- | --- | --- | --- |

| `bloodwaste` | 血液废物 | mL | 实际废物来自能量消耗、蛋白质修复、吸收的浑浊物、酒精、盐、免疫清除和营养过滤。基础过滤能力为 72 mL/h；肠道满时无法过滤。废物负荷达到 40% 后会逐步影响意识和劳动。 |

| `bloodglucose` | 血糖 | 由服务端提供单位 | 血液中可供组织使用的葡萄糖。血糖不足会影响意识和身体机能。 |
| `lactate` | 乳酸 | 由服务端提供单位 | 只有疾跑爆发会缓慢增加乳酸，每秒 0.1 g；连续 10 秒约增加 1 g。劳动、攻击、跳跃和点火不会增加乳酸，其体力消耗另行计算。乳酸不会逐渐削弱普通劳动；满载时会阻止疾跑爆发并强制慢跑。站立、步行、坐姿半衰期分别为 180、300、150 现实秒；循环不足会减慢恢复。肌肉酸痛单独恢复。 |

## 数值如何阅读

带条形图的键会按服务器提供的 `Minimum/Maximum` 投影到 0–1；标签仍显示物理值。功能面板显示百分比倍率。血液循环、疾病恢复、体温调节和环境使用内联文本；悬停可以看到 `PanelMetric.Detail`。趋势箭头来自客户端 `MetricTrendDisplay`，不是新的生理变量。
