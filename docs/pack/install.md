# 安装、启动与首次检查

本页只描述当前工作区可核验的整合包安装结构。启动器仍以你的 MVL 实例为准。

## 安装前

1. 备份实例目录中的 `Mods`、`Logs/服务器相关/ModConfig` 和世界存档。
2. 确认三个 Seraph 模组及其依赖位于 `Mods`；不要把服务端配置复制到客户端覆盖。
3. 保留原始文件名和版本号，条目页中的 DLL/资源证据按文件名索引。

## 首次启动

首次启动后先检查日志中的模组加载、依赖缺失、`功能负责方` 和配置校验结果。然后进入世界：

- 打开 C 键，确认状态快照可以刷新；
- 用 `/vsslssmod check` 验证玩家状态；
- 用 `/vsslssmod compat` 确认水、伤口、环境和倒地能力的提供者；
- 再开始建立饮水、卫生和食物储备。

如果配置校验失败，源码会拒绝新配置并保留旧的有效状态；请先修复日志指出的字段，再重启验证。

## 证据边界

本机索引统计为 129 个安装包/目录、151 个 DLL，其中 146 个可由 ILSpy 读取。原生 DLL 和仅有二进制的模组仍需在运行日志中复核行为。
