# 交通、旅行与环境变化

移动会改变风、活动能量、污染和卫生增长；游泳、划船、攀爬、骑乘等动作按不同活动类型结算消耗。长途旅行前准备饮水、营养信息明确的食物、休息点和伤口护理物品。

## 车辆、船和帐篷的实物路线

1. **车辆**：马车与商队（Cartwrights Caravan） 的配方把车篷、侧帐篷、车板、鞍具和染色/反染色拆成多个网格或桶步骤；先做未染色基础件，再用对应 染料或鞣酸（原字段 `dyes`、`tannin`） 桶配方处理颜色。车体和帐篷的变体必须从配方允许的材料和颜色变体 选择，不能把任意木材代码混用。
2. **船只**：造船模组（Shipwright） 的配方页记录船体与船上部件的输入、输出和变体。装船前把桶、食物、绷带与备用燃料按航程分开；落水后游泳会按独立活动类型结算体力和体温。
3. **手推车兼容**：Carry On、Cartwright 和运输类模组分别拥有搬运、车辆和玩家姿态能力。出现重复速度/承载效果时，管理员先看 `/vsslssmod compat` 的 功能负责方，再调整唯一拥有者。

旅行中开始按压、清洁或绷带动作后，骑乘、游泳、移动、受伤会触发服务端中断；请在安全停靠点护理，不要把 界面进度条当作已经完成护理。
