## 手册 1：合成机制：纺车


概述

[handbooksearch://纺车] 纺车是一种脚踏式合成站，用于将原始纤维纺成线和线。它为在网格中手工合成线提供了更沉浸的替代方案。

使用方法

1. 放置纺车

纺车是一个2x2x2的多方块结构。将其放置在平坦的地面上，并确保周围有足够的空间。

2. 坐下

右键点击纺车以坐下。你的角色会坐在纺车前，准备纺线。

3. 打开合成菜单

坐下后，右键点击任意部位打开纺车界面。这样你可以放入纤维并取出成品。

4. 放入纤维

将可纺纤维（如 [handbooksearch://亚麻纤维] 亚麻纤维）放入输入槽。

5. 开始纺线

坐下并放入纤维后，你的角色会自动开始纺线。纺车会转动，纤维会随时间转化为线。

6. 取出成品

纺线完成后，从输出槽中取出纺好的线。

可纺材料

原版：

亚麻纤维 -&gt; 亚麻线

安装羊毛与更多模组后：

羊毛纤维 -&gt; 羊毛线

安装加勒比花卉区模组后：

棉花纤维 -&gt; 亚麻线

安装肉干模组后：

纸莎草纤维和藻类 -&gt; 亚麻线

便携替代方案

如果你需要在旅途中纺线，可以考虑使用 [handbook://spinningwheel:handbook-dropspindle-title] 手持纺锤。它速度较慢，但无需坐下即可在任何地方使用。

提示

- 纺车比手工在网格中合成线更快

- 你可以在模组设置中调整纺线时间和数量

- 服务器管理员可以将纺车限制为特定玩家职业

## 手册 2：合成机制：飞梭织布机


概述

[handbooksearch://飞梭织布机] 飞梭织布机是一种先进的织布站，可将线织成布料。它因梭子机构在经线间来回飞行而得名，提供了一种沉浸式的布料制作方式。

使用方法

1. 放置织布机

织布机是一个3x2x2的多方块结构。放置前请确保有足够的空间。

2. 坐下

右键点击织布机以坐下。你的角色会坐在织布机前。

3. 打开织布菜单

坐下后，右键点击任意部位打开织布机界面。

4. 放入线

将可织线（如 [handbooksearch://亚麻线] 亚麻线）放入输入槽。不同类型的线会织出不同的布料。

5. 开始织布

坐下并放入线后，你的角色会开始织布。你会看到梭子动画，同时布料逐渐产出。

6. 取出布料

从输出槽中取出织好的布料。

可织材料

原版：

亚麻线 -&gt; 亚麻布

安装羊毛与更多模组后：

羊毛线 -&gt; 羊毛布

羊毛线有多种颜色，织出的布料颜色与所用线色一致。

图案编织

在安装了裁缝之乐和羊毛与更多模组后，织布机解锁 [handbook://spinningwheel:pattern-weaving-guide] 图案编织功能，可制作装饰性方格布料。详细说明请参阅 [handbook://spinningwheel:pattern-weaving-guide] 图案编织指南。

工艺流程

典型的纺织流程为：

1. 收获纤维（亚麻、羊毛、棉花等）

2. 使用 [handbook://spinningwheel:spinning-wheel-guide] 纺车将纤维纺成线

3. 使用织布机将线织成布料

4. 用布料制作衣物、包袋和其他物品

提示

- 每个织布周期默认消耗9根线

- 你可以在模组设置中调整输入/输出数量

- 织布机的梭子动画显示你的织布进度

- 服务器管理员可以将织布机限制为特定玩家职业

## 手册 3：合成机制：图案编织


概述

图案编织是 [handbook://spinningwheel:fly-shuttle-loom-guide] 飞梭织布机上提供的一种高级技术，允许你通过组合不同颜色的线来制作装饰性方格布料。

要求

图案编织需要同时安装裁缝之乐和羊毛与更多模组。若缺少任一模组，图案标签页将不可见。

工作原理

与使用单个输入槽的普通织布不同，图案编织使用一个2x2网格，线的摆放位置决定了方格图案。线按对角线排列：

[ 强调色  ] [ 底色    ]

[ 底色    ] [ 强调色  ]

标准颜色

对于标准方格布（红色、蓝色、绿色等）：

- 强调色（对角线）：彩色线（例如：红色线）

- 底色（对角线）：亚麻线 或 原色羊毛线

深色系

对于深色方格布（深红、深蓝、深绿、深棕）：

- 强调色（对角线）：深色线（例如：深红色线）

- 底色（对角线）：较浅的对应色（例如：红色线）

深色图案将深色线与其非深色变体配对，而非使用亚麻线或原色羊毛线。

步骤

1. 坐在飞梭织布机前

2. 打开织布机界面

3. 切换到图案标签页

4. 将强调色线放入左上角和右下角槽位

5. 将底色线放入右上角和左下角槽位

6. 开始织布以制作方格布

提示

- 强调色线决定输出布料的颜色

- 确保线放置在对角线正确位置

- 标准颜色可使用亚麻线或原色羊毛线作为底色

## 手册 4：合成机制：手持纺锤


概述

[handbooksearch://手持纺锤] 手持纺锤是一种简单便携的工具，可在旅途中将纤维纺成线。它比纺车慢，但无需工作站或坐下。

使用方法

1. 准备工具

将你要纺的纤维放在副手。

将 [handbooksearch://手持纺锤] 手持纺锤拿在主手。

2. 纺线

按住右键以纺线。每批需要按住两次。

3. 取出线

纺线完成后，潜行 + 右键以取出纺好的线。

提示

- 手持纺锤支持与纺车相同的纤维（亚麻、棉花、羊毛等）

- 通过聊天消息（若在配置中启用）或纺线动画观察进度

- 你可以在模组设置中配置是否显示进度消息

- 非常适合旅行或无法使用完整纺车时使用
