# 水、卫生与疾病预防

水的浑浊度、肠道危害、病原字典和化学危害分别保存。蒸馏水无基础浑浊度；雨水、冰融水、井水、河流、湖泊、池塘和沼泽有不同默认值，详见 `SurfaceWaterOptions` 与[配置表](/admin/survival-config-full)。

## 实际流程

- 取水后先过滤或加热；过滤降低病原负荷，加热到 100°C 会清除水中病原字典。
- 清洁双手后再处理食物；脏水会提高手部保留，手到食物有独立转移比例。
- 处理排泄物、动物废弃物和尸体后远离饮水容器；服务器可把这些来源映射为 致病性大肠杆菌、沙门氏菌 或伤口病原。
- 受伤后保持伤口清洁，避免把皮肤病原带入开放伤口。

疾病暴露必须由服务端验证事件触发，粒子效果本身不会自动感染。

## 家庭工坊大缸

生存模拟 1.0.3 在安装家庭工坊（Cottage Industry）时兼容大缸的容器取放水、倾倒端点与雨水收集。传输按实际可用水量进行，并保留、混合水质信息。容量、配方、适用容器、龙头、存档与领地权限仍由家庭工坊管理。

若对应版本接口不受支持，兼容会停用并给出日志提示。管理员可用 /vsslssmod compat 检查兼容是否启用。

## 旱厕与液体粪肥

旱厕收集桶输出液体粪肥浆料；安装天然肥料模组时优先使用其浆料，否则使用生存模拟自带浆料。容量按桶的升数上限计算，不能按普通物品最大堆叠数判断。

接收排泄物时会检查桶的身份、内容物、封口与权限，并保留质量及病原信息；原有固体粪肥会在继续加入时转换为浆料。封口、内容不兼容或已满时先排除条件，再继续使用。粪肥有农业用途，也仍需按污染物管理，处理后清洗双手。

## 从取水到农田的补齐流程

1. 用井、地表水或容器取得水，先查看 C 键水量和水质；`WaterBatch` 同时保存浑浊度、肠道危害、病原字典和化学危害。
2. 加热到 100°C 会清除水中病原字典；过滤降低病原负荷但不自动抹除所有化学危害。洗浴接受 0–45°C 的水，浴缸一次至少 40 L，桶洗一次消耗 0.25 L。
3. 手部污染与食物转移是独立步骤：清洁水只保留少量污染，脏水会保留更多；处理排泄物或尸体后先洗手，再接触食物和饮水容器。
4. 天然肥料模组（Natural Fertilizer） 的桶链使用水、粪便和草料生成成熟肥料；排泄物来源由 SLSS 的厕所/地面动作决定，肥料物品本身不能替代环境卫生。
