## 手册 1：VS 屋顶模组：制作指南

VS 屋顶模组：制作指南

屋顶的制作为：先建造框架，然后向框架添加屋顶材料。

框架

框架类型

木棍 / 竹子 / 树枝

这些前期游戏框架由木棍、竹桩和柴火（树枝）stick&#124;bamboostakes&#124;firewood 制成，同时副手需持有麻线/绳索资源（亚麻纤维、香蒲、纸莎草和野藤）flaxfibers&#124;cattailtops&#124;papyrustops/wildvine-section-north。

木材

这种中后期游戏框架由木板 plank-birch&#124;plank-oak&#124;plank-maple&#124;plank-pine&#124;plank-acacia&#124;plank-kapok&#124;plank-baldcypress&#124;plank-larch&#124;plank-redwood&#124;plank-ebony&#124;plank-walnut&#124;plank-purpleheart&#124;plank-aged 制成，同时副手需持有锤子 hammer-copper&#124;hammer-tinbronze&#124;hammer-bismuthbronze&#124;hammer-blackbronze&#124;hammer-gold&#124;hammer-silver&#124;hammer-iron&#124;hammer-meteoriciron&#124;hammer-steel。

金属

这种后期游戏框架由金属棒 rod-copper&#124;rod-tinbronze&#124;rod-bismuthbronze&#124;rod-blackbronze&#124;rod-gold&#124;rod-silver&#124;rod-iron&#124;rod-meteoriciron&#124;rod-steel&#124;rod-cupronickel&#124;rod-electrum 制成，同时副手需持有锤子 hammer-copper&#124;hammer-tinbronze&#124;hammer-bismuthbronze&#124;hammer-blackbronze&#124;hammer-gold&#124;hammer-silver&#124;hammer-iron&#124;hammer-meteoriciron&#124;hammer-steel。

使用 rightmouse 按钮建造每个框架。

框架可以水平和垂直放置，以创建低坡度和高坡度。角落（外侧和内侧）通过将垂直的屋顶前后组合来创建。

你还可以使用 toolmodeselect（工具模式）选择框架类型（标准、屋檐、屋脊）。此菜单还会提供左/右变体以及手动覆盖坡度和放置位置的功能。

材料

要添加屋顶材料，请手持所需物品/方块，并在框架上按住 shift 的同时按下 rightmouse 按钮。

某些材料可能需要在副手持有工具才能添加。

某些屋顶配方可能还需要你物品栏中的额外资源。更多信息请参阅 [handbook://vsroofing:craftinginfo-recipes] 配方指南。

基础方块

要添加基础（填充）方块，请手持所需方块，并在按住 ctrl 的同时按下 rightmouse 按钮。这些基础方块可以凿刻。

提示：你可以用扳手旋转纹理。你也可以使用 Ctrl 添加更多材料。

锁定

你可以使用锤子 + rightmouse 来切换方块的锁定状态。这将防止任何重新配置。

隐藏横梁

你还可以使用锯子 + rightmouse 来隐藏横梁。这将在隐藏和自动之间切换横梁（即无法再添加横梁）。

提示：并非所有横梁都属于所有方块，如果不生效，请尝试相邻的方块。
