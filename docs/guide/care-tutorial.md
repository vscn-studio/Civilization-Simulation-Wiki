# 护理操作：止血、包扎与清洁

## 受伤后先做这几步

1. 离开危险，按 C 看出血速率、血量与伤口列表。
2. 保持静止并按住 **P** 按压；也可使用 `/vsslssmod pressure`。服务器处理出血最快的开放伤口，按压约减少该伤口 90% 的出血，其他伤口仍需处理。
3. 使用绷带或适用药膏。清洁绷带可以止血，但不能代替清洁污染。
4. 观察实际出血和血量，再补充水、营养并休息。感染另按[疾病百科](/guide/diseases)处理。

## 绷带和药膏有什么不同

| 物品 | 主要作用 | 注意 |
| --- | --- | --- |
| 清洁绷带 | 包扎并止血 | 不降低污染与伤口病原。 |
| 酒精绷带 | 止血，并减少伤口污染和病原 | 污染与病原保留原来的 30%，不是立即完成愈合。 |
| 木贼药膏（芦苇或亚麻） | 缓解疼痛、止血并支持伤口修复 | 一次剂量可作用于多处未愈合伤口；不要连续重复同组治疗。 |
| 蜂蜜硫磺药膏（芦苇或亚麻） | 在药膏作用外提供匹配病原的抗菌效果 | 仍受剂量、酒精或药物负担规则约束。 |

## 用水清洁

**桶洗：** 使用有效水源并保持潜行，温度需在 0～45°C，至少有 0.25 升水，且身体或开放伤口确有清洁需求。完成一次消耗 0.25 升。保持准星目标和手持物不变，观察进度是否完成。

**浴缸：** 在浴缸中保持所需占用状态及潜行或坐姿，水量至少 40 升，温度 0～45°C。完成一次清洁消耗 10 升；肥皂可提供额外清洁效果。低于 10°C 的冷水还会降低身体温度。

清水与脏水的效果不同。脏水可能把病原带到皮肤和开放伤口，不能当作消毒水。洗净身体也不会立即删除已经开始的疾病病程。

## 动作为何中断

移动、跳跃、游泳、骑乘、受伤、传送、睡眠、切换物品或开始另一项交互，都可能中断当前护理。按压还要求持续保持动作；界面进度条出现不代表服务器已经完成结算。需要主动停止时使用 `/vsslssmod cancel`。

## 排泄之后

使用厕所或处理地面污染，完成后清洁双手，再接触食物与饮水容器。排泄动作完成不代表环境已经卫生；厕所和肥料存储是否连接，需要按实际设施核对。

## 1. 先判断要处理什么

打开 C 键角色窗口，先看出血速率、血量、伤口列表、污染、疼痛和疾病；再看水量、胃水、疲劳、睡压与核心温度。`/vsslssmod check` 返回当前服务端检查结果，能帮助区分伤口护理、感染、缺水和环境问题。一次操作只解决对应账本：绷带不会补水，洗澡不会代替抗病原治疗。

## 2. 按压出血

选择伤口后保持静止，执行 `/vsslssmod pressure`，或使用客户端护理动作。服务器选择出血速率最高的开放伤口；按压期间 `WoundCare.Rate` 将该伤口的出血流量乘以 0.1（约减少 90%），其他伤口仍按原速率结算。HUD 显示按压持续时间、按压前总速率和实际速率。

按压会在下列情况结束：移动超过约 0.3 格、尝试移动、跳跃/攀爬/飞行、游泳、骑乘、传送、再次受伤、左/右键操作、睡眠或开始其他治疗；按压心跳超过 0.75 秒也会超时。伤口自然凝血到没有可按压流量时自动完成。按压不是绷带，完成后仍要使用绷带或药膏。

## 3. 使用原版绷带与药膏

原版 `game:bandage-clean` 和 `game:bandage-alcoholed` 由 `NativeBandageBridge` 接管服务端结算，但保留原版的目标选择、应用时间、声音、动作中断和物品扣除。服务器只接受实际消耗恰好一件物品的事务；中断、目标无效或保存失败会恢复物品堆。

| 物品 | 真实效果 |
| --- | --- |
| `bandage-clean` | 对尚未包扎的伤口设置 `BandageQuality=1`，立即止血；不降低污染和伤口病原。 |
| `bandage-alcoholed` | 同样止血，并把伤口污染与伤口病原乘以 0.3；仍需等待修复。 |
| `poultice-reed-horsetail`、`poultice-linen-horsetail` | 对所有未愈合伤口应用药膏；修复强度取物品生命值/7 并夹在 0.2–1，持续 10800 生理秒，缓解疼痛并止血。 |
| `poultice-reed-honey-sulfur`、`poultice-linen-honey-sulfur` | 与药草药膏相同，并标记抗菌路径，降低 `wound-staph`、`wound-local` 等匹配病原；也会产生酒精/药物负担规则。 |

原版动作开始时会取消按压、洗浴、饮水、排泄和闭眼休息等竞争动作；使用药膏的一件物品是一次剂量，但本地效果会遍历所有未愈合伤口。短时间重复同组剂量会增加恶心和药物毒性，详见[治疗定义](/guide/treatments)。

## 4. 清洁身体与开放伤口

### 水桶或水容器

手持有效水源，对准水桶/水容器或水面，按住潜行（Shift）开始清洁；服务器要求水量至少 0.25 L、温度 0–45°C，并且当前身体或开放伤口确实需要清洁。开始后保持潜行、准星目标和手中物品不变；移动、睡眠、受伤、左键、失去水源或切换手持物都会取消。完成一次桶洗消耗 0.25 L。

普通水洗会把身体脏污设置为水残留对应值，并把水中的病原按 25% 接触量加入皮肤/开放伤口；清水会给清洁保护时长，脏水不会给保护。开放伤口的污染会被水残留限制，不能把脏水当作消毒。

### 浴缸

进入已占用的浴缸并保持潜行或坐姿；浴缸必须有至少 40 L、0–45°C 的水。一次浴缸清洁消耗 10 L，清除身体脏污、把皮肤病原减少 90%，开放伤口病原减少 50%，并记录浴缸废水。若浴缸有肥皂电荷，完成时额外调用 `SoapCare.CleanAll`：身体脏污归零、清洁保护至少 24 游戏小时、皮肤病原减半，开放伤口污染和病原减半，并给伤口约 1800 生理秒的清洁保护。

冷水浴（低于 10°C）还会降低皮肤温度和核心温度；浴缸坐姿、潜行和目标占用状态在整个动作期间都必须保持。

## 5. `/vsslssmod clean`、`cancel` 的实际行为

- `/vsslssmod clean` 只启动与手势清洁相同的 5 秒服务端医疗事务；它不会凭空创造水，也不会直接完成清洁。仍需满足潜行、有效水源、静止和伤口/身体确有清洁需求。
- `/vsslssmod cancel` 取消当前按压、清洁或治疗，不返还已经完成并提交的物品事务；未提交的清洁水量会在事务失败时恢复。
- 医疗动作由 `MedicalActionCoordinator` 以玩家 UID 单线程登记，持续 1–30 秒，服务端检查生命代次、位置（移动平方距离不得超过 0.25）、存活状态和 `TriesToMove`，客户端不能伪造完成时间或目标数值。

## 6. 排泄、厕所与肥料闭环

排泄是独立的世界动作，会占用玩家姿态和位置；移动、骑乘、游泳、受伤、睡眠、传送或开始另一项动作会取消。厕所/旱厕路径会把产物交给兼容的粪肥存储适配器；地面排泄则留下污染来源，可能通过水、手和食物传播肠道病原。处理后应洗手、远离饮水点并清理污染，不要把“动作完成”理解为环境已经卫生。

## 7. 一套可执行的玩家流程

1. 受伤后立即停下，`/vsslssmod check`，保持按压直到出血速率显著下降。
2. 使用清洁绷带；若伤口污染或病原负荷高，改用酒精绷带/抗菌药膏。
3. 找到清洁水或已加热的水，先处理身体和开放伤口；脏水只会清除部分污物，并可能增加病原。
4. 观察 C 键中的血量、血液废物、疼痛、伤口愈合和疾病；重复剂量前确认上一次同组治疗已结束。
5. 排泄后处理厕所/肥料或污染地面，洗手，再制作和食用食物。
6. 若症状仍在，按[疾病清单](/guide/diseases)的病原来源与恢复条件处理；按压、清洗和绷带不能替代口服病原治疗。
