## 手册 1：火箭

来源：`assets/vscnfirearrows/config/handbook/firearrows.json`。

制作

火箭是独立物品，箭头附近有干草包和绳扎。搜索“燧石火箭”“铜火箭”等查看各自配方。保留原箭配方的材料、产量和职业限制，额外添加1根绳子和1份干草。所有支持的普通箭均可直接包扎：1支普通箭加1根绳子、1份干草，无序合成1支对应材质的火箭。

点燃与射击

一手持燃烧的火把，另一手持新火箭，约1秒后点燃，左右手均可互换。一次点燃1支。火箭接近火焰、熔岩、燃烧火把或营火也会着火，包括飞行途中接触火源。换弓后优先射出燃烧的火箭。伤害和破碎概率继承对应原箭。不提供绳箭的火箭版本。

燃烧与环境

默认燃烧预算300秒（5分钟）。无风无雨时，地域湿润程度会把持续时间调整为约244～300秒。风、露天雨水继续缩短时间；强风、累计淋雨或极端潮湿还会扑灭火焰。屋顶能挡雨，降雪不按雨水处理。环境潮湿程度参考地域降雨和当前天气，并非空气相对湿度百分比。飞行中按箭与风的相对气流持续判断，可在命中前被吹灭、淋灭或入水熄灭。服务器配置可调整时间和倍率。

命中与回收

燃烧的箭可点燃木材、树叶、植物、布等可燃材质以及有燃料属性的方块，兼容放置后的木制摆件。缺少材质声明的摆件按模型表面主要使用的材质判断。飞行中穿过草等无碰撞植物也可点火，石墙会阻挡点火。遵守领地权限；每支燃烧火箭对同一命中方块只削减一次10点加固，仍有加固值时不可点燃，归零后可燃方块即可着火。零加固值的锁记录不阻止燃烧；石头等不可燃材质不会因加固归零而着火。未点燃或已熄灭的箭不会削减加固。接触石头、金属等不可燃表面通常约4秒熄灭，风雨潮湿会进一步缩短。火焰和烟雾采用原版效果。

状态

名称标注燃烧、燃尽、水灭、风灭、雨灭、潮灭或触物熄灭。烧过的箭熄灭后会失去头部草包与绑绳，箭头保留焦黑痕迹，手持、掉落及射出后的外观一致，且都无法复燃；没有破碎的箭仍可按对应原箭规则拾取并继续作为普通弹药使用。同材质、同状态的火箭最多堆叠64支，不同熄灭原因分开堆叠。燃烧中的箭合并时采用较短的剩余时间，不会补充燃料。收纳、卸载区块或重启不会重置最长燃烧时间。
