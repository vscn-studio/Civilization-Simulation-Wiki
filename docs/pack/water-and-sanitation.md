# 水、卫生与疾病预防

源码把水的浑浊度、肠道危害、病原字典和化学危害分开保存。蒸馏水无基础浑浊度；雨水、冰融水、井水、河流、湖泊、池塘和沼泽有不同默认值，详见 `SurfaceWaterOptions` 与[配置表](/admin/survival-config-full)。

## 实际流程

- 取水后先过滤或加热；过滤降低病原负荷，加热到 100°C 会清除水中病原字典。
- 清洁双手后再处理食物；脏水会提高手部保留，手到食物有独立转移比例。
- 处理排泄物、动物废弃物和尸体后远离饮水容器；服务器可把这些来源映射为 致病性大肠杆菌、沙门氏菌 或伤口病原。
- 受伤后保持伤口清洁，避免把皮肤病原带入开放伤口。

疾病暴露必须由服务端验证事件触发，粒子效果本身不会自动感染。

## 从取水到农田的补齐流程

1. 用井、地表水或容器取得水，先查看 C 键水量和水质；`WaterBatch` 同时保存浑浊度、肠道危害、病原字典和化学危害。
2. 加热到 100°C 会清除水中病原字典；过滤降低病原负荷但不自动抹除所有化学危害。洗浴接受 0–45°C 的水，浴缸一次至少 40 L，桶洗一次消耗 0.25 L。
3. 手部污染与食物转移是独立步骤：清洁水只保留少量污染，脏水会保留更多；处理排泄物或尸体后先洗手，再接触食物和饮水容器。
4. 天然肥料模组（Natural Fertilizer） 的桶链使用水、粪便和草料生成成熟肥料；排泄物来源由 SLSS 的厕所/地面动作决定，肥料物品本身不能替代环境卫生。
